# 多头注意力

## 定义

多头注意力是注意力机制的一种扩展，通过并行运行多个注意力头，让模型能够同时关注输入序列的不同表示子空间。

## 数学表达

对于输入序列，多头注意力定义为：

```
MultiHead(Q, K, V) = Concat(head₁, ..., headₕ)Wᵒ
```

其中每个头：
```
headᵢ = Attention(QWᵢ^Q, KWᵢ^K, VWᵢ^V)
```

## 参数设置

在原始 Transformer 论文中：
- 头数 h = 8
- 每个头的维度 d_k = d_v = d_model / h = 64
- 总维度 d_model = 512

## 优势

1. **表示多样性**：每个头学习不同的关注模式
2. **并行计算**：多个头可并行计算
3. **表达能力**：比单头注意力更强大
4. **可解释性**：不同头可能学习不同的语法/语义关系

## 实现细节

- **线性投影**：每个头有自己的投影矩阵 Wᵢ^Q, Wᵢ^K, Wᵢ^V
- **拼接操作**：所有头的输出拼接后通过 Wᵒ 线性变换
- **残差连接**：通常与残差连接和层归一化结合使用

## 应用场景

1. **自注意力**：编码器和解码器中的自注意力层
2. **编码器-解码器注意力**：连接编码器和解码器
3. **跨模态注意力**：多模态任务中的注意力机制
