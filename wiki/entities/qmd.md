# qmd

## 描述
qmd 是一个本地 Markdown 文件搜索引擎，提供混合 BM25/向量搜索和 LLM 重新排名功能，完全在设备上运行。

## 属性
- **类型**：本地搜索引擎
- **搜索技术**：混合 BM25/向量搜索
- **重新排名**：LLM 重新排名
- **部署**：完全在设备上运行，无需网络连接
- **接口**：CLI 和 MCP 服务器

## 在 LLM Wiki 系统中的作用
### 搜索扩展
当 wiki 规模较小时，`index.md` 文件足够进行导航。但随着 wiki 增长，需要更强大的搜索功能：

1. **小规模**：使用 `index.md` 文件手动导航
2. **中大规模**：使用 qmd 进行高效搜索
3. **混合搜索**：结合关键词（BM25）和语义（向量）搜索
4. **智能排序**：使用 LLM 对结果进行重新排名

### 集成方式
1. **CLI 集成**：LLM 可以通过 shell 命令调用 qmd
2. **MCP 服务器**：LLM 可以将其作为原生工具使用
3. **自动化搜索**：在 ingest 和 query 操作中自动使用

## 技术特点
### BM25 搜索
- **关键词匹配**：传统的文本搜索算法
- **快速检索**：适合精确关键词查找
- **可解释性**：结果基于词频和文档长度

### 向量搜索
- **语义理解**：基于嵌入向量的相似性搜索
- **概念匹配**：找到语义相关但关键词不同的内容
- **上下文感知**：理解查询的深层含义

### LLM 重新排名
- **质量排序**：使用 LLM 对初步结果进行重新排序
- **相关性评估**：基于内容相关性而非单纯匹配度
- **个性化**：可以根据用户偏好调整排序

## 优势
1. **隐私保护**：完全本地运行，数据不出设备
2. **混合搜索**：结合关键词和语义搜索的优势
3. **智能排序**：LLM 重新排名提高结果质量
4. **灵活集成**：支持 CLI 和 MCP 两种接口

## 使用场景
1. **知识检索**：在大型 wiki 中快速找到相关信息
2. **内容发现**：发现语义相关但关键词不同的页面
3. **研究辅助**：支持复杂的研究查询
4. **自动化处理**：LLM 在 ingest 时自动搜索相关页面

## 替代方案
如果不需要完整的 qmd，可以：
1. **简单脚本**：LLM 可以帮忙编写简单的搜索脚本
2. **现有工具**：使用 grep、ripgrep 等命令行工具
3. **渐进采用**：从小规模开始，随 wiki 增长而升级
