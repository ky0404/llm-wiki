# Python 速通学习进度追踪

> 目标：7天速通Python，能自己写代码处理数据，不再依赖AI生成代码
> 原则：**先自己写，报错自己排查，禁止直接问AI要答案**

---

## 学习原则（必须遵守）

```
🚫 禁止做法：
1. 遇到报错就问 AI
2. 直接复制代码运行
3. 看懂代码就等于会了
4. 遇到问题就跳过

✅ 正确做法：
1. 先自己手写代码，不管对错
2. 报错先自己排查 10 分钟
3. 必须手敲代码，不能复制粘贴
4. 查文档 / 搜索引擎 / 论坛
5. 跑通后再对比参考答案
```

## 核心速查表

### 变量与类型
```python
a = 10          # int
b = 3.14        # float
c = "hello"     # str
d = True        # bool
e = [1, 2, 3]   # list
f = (1, 2)      # tuple
g = {"a": 1}    # dict
h = {1, 2, 3}   # set
```

### 分支结构
```python
if condition:
    # do something
elif condition2:
    # do another
else:
    # default
```

### 循环结构
```python
for i in range(10):    # 0-9
    print(i)

while condition:
    # do something
    break   # 跳出循环
    continue  # 跳到下次
```

### 列表操作
```python
lst = [1, 2, 3]
lst.append(4)      # 末尾添加
lst.insert(0, 0)  # 插入
lst.pop()         # 删除末尾
lst.sort()        # 排序
[x for x in lst if x > 0]  # 筛选
```

### 字符串
```python
s = "hello"
s.upper()         # 大写
s.split(',')      # 拆分
','.join(['a','b'])  # 拼接
f"{name} is {age}"  # 格式化
```

### 字典
```python
d = {"name": "张三", "age": 20}
d["name"]           # 获取
d.get("name", "默认")  # 安全获取
d.keys()            # 所有键
d.values()          # 所有值
d.items()           # 所有键值对
```

### 函数
```python
def func(a, b=1, *args, **kwargs):
    return a + b
```

### 文件操作
```python
with open("file.txt", "r", encoding="utf-8") as f:
    content = f.read()
    
with open("out.txt", "w") as f:
    f.write("hello")
```

## 常见报错速查

| 报错 | 原因 | 解决方法 |
|------|------|----------|
| SyntaxError | 语法错误 | 检查缩进、括号、引号、冒号 |
| NameError | 变量未定义 | 检查变量名拼写 |
| IndentationError | 缩进错误 | Python用缩进表示代码块 |
| TypeError | 类型错误 | 字符串不能用+拼接数字 |
| IndexError | 索引越界 | 列表索引从0开始 |
| FileNotFoundError | 文件不存在 | 检查路径 |
| KeyError | 字典键不存在 | 用get()方法 |
