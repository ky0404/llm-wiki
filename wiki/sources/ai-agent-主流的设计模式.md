# AI Agent 主流的设计模式

## 核心要点

1. **ReAct**：Reasoning + Acting，结合推理与执行
2. **Reflection**：自我反思，错误修正
3. **LATS**：Plan → Act → Observe → Think 循环
4. **模式对比**：各适用于不同场景
