# Understanding Model Context Protocol (MCP)

## 核心要点

1. **MCP 定义**：模型上下文协议，AI 模型与现实世界数据/工具的通用接口
2. **设计目标**：标准化 AI 与外部系统的交互
3. **核心组件**：Resources、Tools、Prompts
4. **应用场景**：开发者工具集成、数据源连接
