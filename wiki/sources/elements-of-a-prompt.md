# Elements of a Prompt

## 核心要点

1. **指令（Instructions）**：告诉模型要执行的任务
2. **上下文（Context）**：提供背景信息
3. **输入数据（Input Data）**：需要处理的内容
4. **输出指示（Output Indicator）**：指定输出格式
