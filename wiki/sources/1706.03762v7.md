# Attention Is All You Need

## 核心贡献

提出 Transformer 架构，完全基于注意力机制，摒弃循环和卷积结构，实现并行化训练。

## 架构组成

- **Encoder**：6 层，每层包含多头自注意力 + 前馈网络
- **Decoder**：6 层，额外包含Encoder-Decoder注意力
- 残差连接 + Layer Normalization

## 关键技术

### Scaled Dot-Product Attention
`Attention(Q, K, V) = softmax(QK^T / √d_k)V`

### Multi-Head Attention
并行运行 h=8 个注意力头，每个头的维度 d_k = d_v = 64。

### Positional Encoding
使用正弦函数编码位置信息：`PE(pos, 2i) = sin(pos / 10000^(2i/d_model))`

## 实验结果

| 任务 | 模型 | BLEU |
| --- | --- | --- |
| WMT 2014 En-De | Transformer | 28.4 |
| WMT 2014 En-Fr | Transformer | 41.8 |

训练成本仅为之前最佳模型的极小部分。

## 优势

1. 并行化：O(1) 顺序操作
2. 长距离依赖：O(1) 路径长度
3. 可解释性：注意力头学习不同语法/语义任务
