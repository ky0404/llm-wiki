# Best Practices for Prompt Engineering with OpenAI API

## 核心要点

1. **清晰指令**：明确、具体的任务描述
2. **结构化输出**：指定格式、长度、风格
3. **示例使用**：Few-shot 提供示例
4. **迭代优化**：基于结果调整提示词
