## 摘要

本文系统论述结构化提示词（Structured Prompt）的思想与实践。作者云中江树是 LangGPT 项目创始人，最早在国内提出结构化、模板化编写 Prompt 的范式。结构化 Prompt 如同写文章一样写提示词，使用标题、子标题、段落等语法结构组织内容，配合各类模板提升 Prompt 性能。

## 核心要点

- 结构化 Prompt：像写文章一样写 Prompt，使用模板组织内容
- 与 CRISPE 框架区别：CRISPE 只提供内容框架，结构化提供模板化形式
- LangGPT：作者开源的结构化 Prompt 项目，受网易字节等大厂认可
- 模板优势：便于阅读、表达、复用，可像 PPT 模板一样选择或创造

## 结构化 Prompt 示例

- Role：定义角色
- Profile：定义背景信息
- Goals：定义目标
- Skills：定义技能
- Workflow：定义工作流程
- Output Format：定义输出格式
