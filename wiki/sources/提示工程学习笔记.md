# 提示工程学习笔记

## 核心要点

1. **提示工程定义**：开发和优化提示词的学科，帮助用户将大模型用于各种应用场景
2. **提示词组成要素**：
   - 指令（Instruction）：给模型下达指令
   - 上下文（Context）：提供额外上下文信息
   - 输入数据（Input Data）：需要处理的数据
   - 输出指示（Output Indicator）：指定输出格式
3. **常用技巧**：Few-shot、CoT、ReAct 等
4. **与智能体结合**：LangChain 实现多种 Agent 类型
