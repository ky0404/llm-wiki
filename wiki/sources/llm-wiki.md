# LLM Wiki

## 核心要点

1. **模式定义**：使用 LLM 构建个人知识库的模式
2. **核心问题**：RAG 每次都从零发现知识，无累积
3. **解决方案**：内化知识、持久化、链接关联
4. **可复制**：可粘贴到各类 LLM Agent（Codex、Claude Code、OpenCode）
