# 高级 RAG 技术学习笔记

## 核心要点

1. **RAG 定义**：检索增强生成（Retrieval-Augmented Generation）
2. **解决问题**：缺乏领域知识、无法获取实时信息、生成虚假内容
3. **核心技术**：向量检索、块优化、 reranking、多路召回
4. **高级技术**：Graph RAG、Hybrid Search、Agentic RAG
