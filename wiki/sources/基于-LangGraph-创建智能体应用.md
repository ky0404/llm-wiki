# 基于 LangGraph 创建智能体应用

## 核心要点

1. **LangGraph 定位**：LangChain 的智能体应用库，支持复杂多智能体系统
2. **核心优势**：状态图（State Graph）精细控制，支持循环流程
3. **对比 AgentExecutor**：更透明的控制，更适合构建复杂智能体
4. **关键概念**：Node、Edge、State、Checkpoint
