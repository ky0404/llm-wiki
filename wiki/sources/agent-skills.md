# Agent Skills

## 核心要点

1. **定义**：模块化能力扩展，每个 Skill 打包指令、元数据和可选资源
2. **关键优势**：
   - 专业定制：为特定领域定制能力
   - 减少重复：创建一次，自动使用
   - 文件系统化：基于文件系统的可复用资源

3. **与 Prompt 的区别**：Prompt 是会话级指令，Skills 按需加载
