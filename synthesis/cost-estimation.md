**按实际使用量估算**：
- 假设每日100次查询，其中20%使用云端模型
- 平均每次云端查询消耗2000 token
- 月度云端token = 100 × 20% × 30 × 2000 = 120万token
- 成本 ≈ 120万 × $0.15/1M = $0.18（GPT-4o-mini）

## 4. 成本优化建议

### 4.1 降低云端API成本
1. **使用更便宜的模型**：
   - GPT-4o-mini 替代 GPT-4o（$0.15/1M vs $5/1M）
   - Claude 3.5 Haiku（$0.25/1M输入）
   - 国内模型（文心、通义，$0.008-0.02/1K tokens）

2. **缓存常用查询结果**：
   ```python
   # Redis缓存
   cached = redis.get(query_hash)
   if cached:
       return cached
   # 否则调用API
   result = call_cloud_api(query)
   redis.setex(query_hash, 3600, result)  # 缓存1小时
   ```

3. **智能路由优化**：
   - 简单查询强制本地
   - 设置月度预算上限
   - 用户选择"经济模式"

### 4.2 降低硬件成本
- 使用现有硬件（如已有≥8GB显存GPU）
- 租赁云GPU（按需，$0.3-0.5/小时）
- 共享GPU资源（多项目共用）

### 4.3 降低人力成本
- 自动化运维（监控、备份、告警）
- 培训现有团队（减少外部依赖）
- 使用托管服务（方案C可减少运维）

### 5.1 假设收益
| 收益项 | 年度价值 |
|--------|----------|
| 知识检索效率提升（节省时间） | $50,000 |

| 可扩展的知识管理（支持增长） | $20,000 |
| **总年度收益** | **$100,000** |

### 5.2 ROI计算（方案B，12个月）
```
总投入（不含人力）: $33,290
总收益（12个月）: $100,000
ROI = (收益 - 投入) / 投入 × 100%
ROI = ($100,000 - $33,290) / $33,290 × 100% = 200%
```

**投资回收期**：约4个月

## 6. 成本监控与告警

### 6.1 监控指标
```python
# 每日成本报告
def daily_cost_report():
    cloud_spend = get_cloud_spend_last_24h()
    budget_daily = 50  # 美元
    
    if cloud_spend > budget_daily * 1.1:
        send_alert(f"日成本超预算: ${cloud_spend}")
    
    return {
        "date": date.today(),
        "cloud_spend": cloud_spend,
        "budget": budget_daily,
        "status": "ok" if cloud_spend <= budget_daily else "exceeded"
    }
```
