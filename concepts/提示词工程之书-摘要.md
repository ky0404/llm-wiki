# 提示词工程之书摘要

## 概述
提示词工程（Prompt Engineering）是优化与大型语言模型（[[concepts/llm]]）交互的技术，通过精心设计输入提示来获得更好的输出结果。

## 核心提示技术

### 1. 零样本提示（Zero-Shot Prompting）
**定义**：不提供任何示例，直接给出任务描述。

**示例**：
```
将以下英文翻译成中文："Hello, world!"
```

**优点**：
- 简单直接
- 不需要示例数据
- 适用于简单明确的任务

**缺点**：
- 复杂任务效果有限
- 可能产生歧义
- 需要清晰的指令

### 2. 少样本提示（Few-Shot Prompting）
**定义**：提供少量示例来演示任务。

**示例**：
```
将英文翻译成中文：
示例1: "Hello" -> "你好"
示例2: "World" -> "世界"
现在翻译："Hello, world!" -> 
```

**优点**：
- 明确任务格式
- 提高输出一致性
- 适用于模式化任务

**缺点**：
- 需要示例数据
- 可能过拟合示例
- 增加提示长度

### 3. 思维链提示（Chain-of-Thought, CoT）
**定义**：要求模型展示推理步骤。

**示例**：
```
问题：小明有5个苹果，给了小红2个，又买了3个，现在有多少个？
让我们一步步思考：
1. 最初有5个苹果
2. 给了小红2个，剩下5-2=3个
3. 又买了3个，现在有3+3=6个
所以答案是6个。
```

**优点**：
- 提高复杂问题准确率
- 使推理过程透明
- 便于调试和验证

**缺点**：
- 增加响应长度
- 可能产生错误推理链
- 需要更多计算资源

### 4. 指令提示（Instruction Prompting）
**定义**：使用明确的指令格式。

**示例**：
```
你是一个翻译助手。请将以下英文翻译成中文，保持专业语气。
英文："The quick brown fox jumps over the lazy dog."
中文：
```

**优点**：
- 明确角色和任务
- 控制输出风格
- 提高任务适应性

**缺点**：
- 需要精心设计指令
- 可能限制创造性
- 指令可能冲突

## 技术对比

| 维度 | 零样本 | 少样本 | 思维链 | 指令提示 |
|------|--------|--------|--------|----------|
| **示例需求** | 无 | 需要 | 可选 | 无 |
| **复杂度** | 低 | 中 | 高 | 中 |
| **一致性** | 低 | 高 | 中 | 高 |
| **透明度** | 低 | 中 | 高 | 中 |
| **适用场景** | 简单任务 | 模式化任务 | 复杂推理 | 角色任务 |

## 进阶技术

### 1. 自洽性（Self-Consistency）
**原理**：生成多个推理路径，选择最一致的答案。

**应用**：数学问题、逻辑推理

### 2. 思维树（Tree of Thoughts）
**原理**：探索多个推理路径，选择最佳路径。

**应用**：复杂规划、创意生成

### 3. 程序辅助语言模型（PAL）
**原理**：让模型生成代码来解决问题。

**应用**：数学计算、数据分析

### 4. 反应（ReAct）
**原理**：结合推理（Reasoning）和行动（Action）。

**应用**：工具使用、多步任务

## 在 LLM Wiki 中的应用

### 知识提取
- **指令提示**：明确提取特定类型信息
- **少样本提示**：演示摘要或分类格式
- **思维链**：复杂概念的逐步解析

### 知识组织
- **零样本提示**：简单分类任务
- **指令提示**：遵循特定格式要求
- **少样本提示**：保持一致性

### 查询回答
- **思维链**：复杂问题的逐步推理
- **少样本提示**：保持回答格式一致
- **指令提示**：控制回答风格和深度

## 最佳实践

### 提示设计原则
1. **明确性**：清晰无歧义的任务描述
2. **具体性**：提供具体要求和约束
3. **上下文**：提供足够的背景信息
4. **结构化**：使用清晰的格式和分隔符
5. **迭代优化**：基于反馈改进提示

### 避免常见问题
1. **歧义指令**：导致不可预测的输出
2. **过长提示**：超出模型上下文限制
3. **矛盾要求**：相互冲突的指令
4. **缺乏约束**：过于开放导致无关输出

### 测试和评估
1. **多样化测试**：在不同输入上测试提示
2. **一致性检查**：确保输出格式一致
3. **质量评估**：人工或自动评估输出质量
4. **持续优化**：基于使用反馈改进
