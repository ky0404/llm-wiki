# 低秩分解

## 定义

低秩分解是将一个矩阵表示为两个或多个低秩矩阵乘积的技术，用于压缩和近似表示高维数据。

## 数学表达

给定矩阵 W ∈ ℝ^(d×k)，低秩分解表示为：
```
W ≈ BA
```
其中：
- B ∈ ℝ^(d×r)
- A ∈ ℝ^(r×k)
- rank r << min(d, k)

## 在 LoRA 中的应用

LoRA（Low-Rank Adaptation）使用低秩分解表示权重更新：
```
ΔW = BA
```
其中：
- W₀: 预训练权重（冻结）
- ΔW: 适应过程中的权重更新
- B, A: 可训练的低秩矩阵

## 优势

1. **参数高效**：从 d×k 参数减少到 (d + k)×r 参数
2. **计算高效**：低秩矩阵运算更快
3. **内存节省**：存储和传输更少参数
4. **快速切换**：不同任务只需替换 B 和 A

## 秩的选择

- **理论依据**：ΔW 具有内在低秩特性
- **经验结果**：r=1 或 r=2 通常足够
- **权衡**：秩越高表达能力越强，但参数越多

## 与其他方法的对比

| 方法 | 可训练参数 | 推理延迟 | 特点 |
| --- | --- | --- | --- |
| LoRA | ~0.01% | 无 | 低秩分解 |
| Adapter | ~1% | 有 | 瓶颈层 |
| Prefix Tuning | ~0.1% | 有 | 虚拟token |
| BitFit | ~0.1% | 无 | 仅偏置 |

## 应用领域

1. **参数高效微调**：LoRA 的核心技术
2. **矩阵补全**：推荐系统
3. **数据压缩**：图像和信号处理
4. **降维**：主成分分析（PCA）
