# Function Calling

让LLM调用外部函数/工具的能力。

## 核心机制

1. 定义函数签名
2. 模型识别调用意图
3. 执行函数并返回结果
4. 模型生成最终回复

## 应用场景

- 数据库查询
- API调用
- 代码执行
- 文件操作

## 技术要点

- 函数描述清晰
- 参数校验
- 错误处理
