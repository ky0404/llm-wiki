## 核心要点
本文列出了提示工程中常用的非 IDE 工具，涵盖多个类别：
- **提示开发、测试与链式调用**：
  - [[entities/langchain]]：结合 LLM 与其他计算或知识源的库。
  - PromptAppGPT：低代码提示驱动的快速应用开发框架。
  - Dust.tt：图形化 UI 构建提示链的平台。
  - OpenPrompt：基于 PyTorch 的提示学习框架。
  - BetterPrompt：推送至生产前测试 LLM 提示的测试套件。
  - PromptFlow：低代码工具，集成 LLM、提示、Python 函数和条件逻辑。
- **其他工具**：
  - GPT Index：便于使用大型外部知识库的数据结构。
  - LMQL：用于语言模型的专用查询语言。
  - LLMStack：开源无代码平台，用于构建生成式 AI 应用、聊天机器人和智能体。
